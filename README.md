# Life Simulator Game (Modern 9:16 Mobile Edition)

A sleek, minimalist, deeply simulated Life Simulator Game built in HTML, CSS, and modern JavaScript. Designed in a native 9:16 mobile aspect ratio, centered with an elegant dark luxury theme on desktop, and ready for future export to Android, Capacitor, WebView, or Game Studio.

---

## 🚀 How to Run

### Option 1: One-Click Desktop Launcher (Recommended)
Simply double-click **`run_game.command`** in this folder! It will automatically launch the local Python server and open your default browser to `http://localhost:8080`.

### Option 2: Command Line
Open Terminal, navigate to this folder, and run:
```bash
python3 -m http.server 8080
```
Then visit **`http://localhost:8080`** in Chrome, Safari, or your preferred browser.
